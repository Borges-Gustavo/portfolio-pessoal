Portfólio

Portfólio Pessoal Responsivo com Tema Moderno

Sobre o Projeto

Este portfólio é um projeto pessoal desenvolvido com o objetivo de apresentar minhas habilidades, experiências e projetos realizados. Apresenta um design moderno com tema dark, sidebar navegável e seções dinâmicas para uma experiência de usuário excepcional.

O portfólio utiliza um layout responsivo com navegação intuitiva, permitindo que visitantes facilmente explorem minhas habilidades, cursos realizados, projetos desenvolvidos e entrem em contato comigo.

Tecnologias Utilizadas

HTML5 CSS3 JavaScript Vanilla Responsive Design FontAwesome Icons CSS Grid & Flexbox

Recursos Principais

  • Design Dark Mode: Tema escuro elegante com opção de light mode integrada
  • Sidebar Navegável: Menu lateral sticky com navegação para todas as seções do portfólio
  • Sobre Mim: Seção com apresentação pessoal, objetivos e informações relevantes
  • Habilidades: Showcasing de conhecimentos técnicos com linguagens e tecnologias
  • Cursos: Lista de cursos e certificações relevantes para minha formação
  • Projetos: Galeria com navegação de projetos e overlays interativos ao passar o mouse
  • Contato: Múltiplos canais de contato (Email, WhatsApp, LinkedIn, GitHub)
  • Responsivo: Funciona perfeitamente em desktop, tablet e mobile

Objetivos Alcançados

  • Criar um portfólio profissional que destaque meus melhores projetos
  • Implementar design moderno e atrativo com tema roxo e verde
  • Desenvolver interface responsiva e fácil de navegar
  • Demonstrar proficiência em desenvolvimento web frontend
  • Fornecer múltiplos pontos de contato para oportunidades

O que Aprendi

  • Desenvolvimento de layout com CSS Grid e Flexbox avançado
  • Implementação de dark mode com CSS custom properties
  • Animações suaves e transições usando CSS3
  • JavaScript vanilla para manipulação de DOM e eventos
  • Design responsivo com media queries e mobile-first approach
  • Otimização de performance e acessibilidade web

Características de Design

  • Paleta de Cores: Roxo (#b366ff) como cor primária e verde (#22c55e) como secundária
  • Tipografia: Fontes modernas para melhor legibilidade
  • Ícones: FontAwesome 6.5.1 para ícones consistentes e profissionais
  • Espacejamento: Uso generoso de espaço em branco para respirabilidade
  • Animações: Transições suaves em hover e interações do usuário
